CHRIS LIGHT ELECTRICAL SERVICES WEBSITE
========================================

A responsive branded website with the supplied founder/CEO and electrical-services photos placed prominently at the top, plus an electrical photo gallery.

Files:
- index.html: complete website
- assets/: supplied brand images and cropped electrical detail images

Preview:
Open index.html in a browser. No build step is required.

Publish online:
1. Upload all files and the assets folder to a static host such as Netlify, GitHub Pages, or your hosting control panel.
2. Ensure index.html is at the published root.
3. To use chrislightelectricalservices.com, register the domain if available and connect its DNS to the hosting provider. This package does not register a domain or publish the site publicly.
